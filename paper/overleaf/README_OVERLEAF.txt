HOW TO COMPILE THIS PAPER ON OVERLEAF:
=========================================

1. Go to Overleaf (https://www.overleaf.com).
2. Click "New Project" -> "Upload Project".
3. Select and upload the file:
   Adaptive_Ingress_Admission_Control_Overleaf.zip
4. In Overleaf, make sure the root document is set to "main.tex" (default).
5. Click "Recompile".
6. The single-column conference paper will compile cleanly to PDF.

Package Contents:
- main.tex: The complete LaTeX document matching the Springer LNCS / Single-Column conference format.
- figures/: Directory containing all publication vector PNG figures (architecture, gpu_repeatability, data_selection, reserved_operating_points, long_email_tradeoff, latency_tuning).
